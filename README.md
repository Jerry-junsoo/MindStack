# MindStack
## AI-Based Technical Language Simplifier

**COMP365 Team Project – North Carolina A&T State University**

### 1. Project Overview

MindStack is an AI-based technical language simplifier designed to make technical documentation easier to understand while preserving its original meaning and factual accuracy.

The project uses a language model to simplify technical passages from several computing-related areas. Human evaluation and readability measurements are used to examine the quality of the simplified results.

### 2. Dataset

The project dataset contains 30 technical passages collected from sources including Microsoft Learn, Microsoft Support, and Cisco.

The dataset includes five categories:

| Category | Number of Passages |
|---|---:|
| Cloud Computing | 10 |
| Databases | 5 |
| Networking | 5 |
| Security | 5 |
| Software Engineering | 5 |
| **Total** | **30** |

The `Passages.csv` file contains the passage ID, category, source URL, original text, and word count.

### 3. Technology and Development Environment

The project uses:

- Python
- Google Colab
- Google Drive
- Hugging Face Transformers
- Qwen2.5-1.5B-Instruct

The team uses prompt engineering to guide the language model. The model is not fine-tuned for this project.

**Why Google Colab?**

Google Colab was selected as the development environment because it provides a browser-based Python notebook environment that integrates with Google Drive. This allows team members to work with the notebook and project files without requiring identical local development environments.

Colab also supports the Python libraries and model workflow used in this project. Keeping development in Colab simplifies access to the notebook and helps maintain a consistent workflow across the team.

Google Drive is used to store project files, while GitHub provides version control and a central location for sharing project code and documentation.

### 5. How to Run the Project

1. Download or clone the MindStack repository from GitHub.
2. Open Google Colab at https://colab.research.google.com/.
3. Upload or open `COMP365_Technical_Language_Simplifier_Prototype.ipynb`.
4. Place the required CSV files in the `COMP365_Team_Project` folder in Google Drive.
5. Mount Google Drive when prompted by the notebook.
6. Execute the notebook cells in order.
7. Review the generated simplified passages and evaluation results.

**Important:** The notebook currently uses the Google Drive folder path:

`/content/drive/MyDrive/COMP365_Team_Project`

Make sure the folder and required files are available at that location before running the notebook.

### 7. Reproducibility

To reproduce the project, users should have:

- A Google account with access to Google Colab and Google Drive.
- The project notebook and required CSV files.
- Internet access to load the required Python libraries and language model.
- A compatible Colab runtime with sufficient resources.

The notebook contains the project workflow, while the CSV files provide the input data and saved outputs needed to review the results.

For consistent results, use the same dataset, model, and notebook workflow documented in this repository.
